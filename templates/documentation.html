01

Abstract

This project presents a Smart Game Strategy and Decision-Making System developed as part of the B.Tech Computer Science and Engineering — Artificial Intelligence curriculum. The system implements two pivotal AI heuristic search algorithms: A* (A-Star) and AO* (AO-Star), demonstrating their practical applications in game environments and decision-making scenarios.

The A* algorithm, governed by the evaluation function f(n) = g(n) + h(n), is implemented as an interactive grid-based pathfinding system where users can define start/end positions, add obstacles, and observe the optimal path being computed in real-time. The AO* algorithm is realized through an AND-OR graph visualization that models decomposable problems and computes optimal solution graphs through heuristic cost propagation.

Additionally, the system features an interactive Tic-Tac-Toe game where an AI opponent uses the Minimax algorithm with Alpha-Beta Pruning to make optimal decisions, demonstrating how game-theoretic algorithms connect to the broader A* and AO* framework. The system is built using Python 3 with Flask for the backend, and HTML5, CSS3, and JavaScript for the frontend, providing a fully interactive, visually rich educational platform.

02

Introduction

Artificial Intelligence (AI) has revolutionized the way computers approach problem-solving, particularly in domains requiring search, planning, and decision-making under uncertainty. Among the most fundamental and widely applied AI techniques are heuristic search algorithms, which guide the search process using domain-specific knowledge to find solutions efficiently.

Two landmark algorithms in this domain are:

  • A* Algorithm (1968): Introduced by Peter Hart, Nils Nilsson, and Bertram Raphael, A* combines the benefits of Dijkstra's algorithm (completeness and optimality) with greedy best-first search (efficiency) using an admissible heuristic function.
  • AO* Algorithm (1980): Developed by Nils Nilsson, AO* extends the search paradigm to AND-OR graphs, enabling the solution of problems that can be decomposed into sub-problems (AND nodes) or allow alternative solutions (OR nodes).

This project explores both algorithms through interactive visualizations, making their operation transparent and educational. Games provide an ideal testbed for AI algorithms because they have well-defined rules, clear objectives, and measurable outcomes. The Tic-Tac-Toe game arena demonstrates the Minimax algorithm with Alpha-Beta Pruning, which is deeply connected to the AO* framework for game tree search.

03

Problem Statement

In many real-world applications — from autonomous navigation and robot planning to game strategy and medical decision support — intelligent systems must efficiently search through vast solution spaces to find optimal or near-optimal solutions. The challenge lies in:

  • Navigating large search spaces without exhaustively exploring every possibility (exponential time complexity).
  • Handling problems that decompose into mandatory sub-goals (AND conditions) and alternative approaches (OR conditions).
  • Making real-time decisions in game environments where the opponent is also trying to optimize their strategy.
  • Providing transparent, explainable AI that allows users to understand and trust the decision-making process.

This project addresses these challenges by implementing A* for shortest-path problems, AO* for decomposable decision problems, and Minimax with Alpha-Beta Pruning for adversarial game play — all within a unified, interactive educational platform.

Algorithms

8.1 A* Search Algorithm

A* is an informed search algorithm that finds the least-cost path from a start node to a goal node. It combines actual cost with heuristic estimation:

f(n) = g(n) + h(n)
A* Pseudocode
OPEN = {start}
CLOSED = {}
g[start] = 0
f[start] = h(start, goal)

WHILE OPEN is not empty:
    current = node in OPEN with min f value
    IF current == goal:
        RETURN reconstruct_path(current)
    
    REMOVE current from OPEN
    ADD current to CLOSED
    
    FOR each neighbor of current:
        IF neighbor in CLOSED: continue
        tentative_g = g[current] + cost(current, neighbor)
        
        IF neighbor not in OPEN:
            ADD neighbor to OPEN
        ELIF tentative_g >= g[neighbor]: continue
        
        came_from[neighbor] = current
        g[neighbor] = tentative_g
        f[neighbor] = g[neighbor] + h(neighbor, goal)

RETURN failure (no path exists)

8.2 AO* Search Algorithm

AO* searches AND-OR graphs where some nodes require ALL sub-goals (AND) and others need just ONE sub-goal (OR):

AO* Pseudocode
FUNCTION AO_STAR(node):
    IF node is terminal:
        RETURN h(node)   // Leaf cost
    
    best_cost = ∞
    FOR each child_group of node:
        group_cost = edge_cost
        
        IF child_group is AND:
            // Must solve ALL children
            FOR each child in group:
                group_cost += AO_STAR(child)
        ELSE (OR):
            // Choose BEST child
            group_cost += min(AO_STAR(c) for c in group)
        
        IF group_cost < best_cost:
            best_cost = group_cost
            best_group = child_group
    
    node.cost = best_cost
    node.solved = TRUE
    RETURN best_cost

8.3 Minimax with Alpha-Beta Pruning

Minimax is a decision algorithm for two-player zero-sum games. Alpha-Beta Pruning eliminates branches that cannot affect the final decision:

Minimax with Alpha-Beta Pseudocode
FUNCTION MINIMAX(state, depth, is_max, α, β):
    IF terminal(state) or depth == 0:
        RETURN evaluate(state)
    
    IF is_max:  // AI's turn (maximize)
        best = -∞
        FOR each move in moves(state):
            val = MINIMAX(apply(move), depth-1, FALSE, α, β)
            best = max(best, val)
            α = max(α, best)
            IF β ≤ α: BREAK  // Beta cutoff (prune)
        RETURN best
    
    ELSE:       // Human's turn (minimize)
        best = +∞
        FOR each move in moves(state):
            val = MINIMAX(apply(move), depth-1, TRUE, α, β)
            best = min(best, val)
            β = min(β, best)
            IF β ≤ α: BREAK  // Alpha cutoff (prune)
        RETURN best

Applications

🗺

GPS Navigation

A* is the backbone of GPS navigation systems, finding shortest routes in road networks where h(n) is the straight-line distance to the destination.

🤖

Robotics

AO* is used in robot motion planning for assembly tasks where multiple sub-tasks (AND) must be completed in sequence to achieve the overall goal.

🎮

Video Games

A* powers NPC pathfinding in games. AO* and Minimax handle strategic decision trees in board games, chess engines, and strategy games.

🏥

Medical Diagnosis

AO* models diagnostic decision trees where combinations of symptoms (AND) or alternative explanations (OR) lead to diagnoses.

🔗

Network Routing

A* finds optimal data packet routes in computer networks, balancing actual distance traveled with estimated remaining path.

✈

Flight Planning

A* computes optimal flight paths considering fuel cost, wind conditions, and air traffic, balancing multiple cost factors simultaneously.

Advantages

A* Algorithm

  • ✓ Guaranteed to find the optimal (lowest cost) path when heuristic is admissible.
  • ✓ Complete — will always find a solution if one exists.
  • ✓ Flexible heuristic function can be tailored to the domain.
  • ✓ Significantly faster than uninformed search like BFS/DFS in practice.
  • ✓ Well-studied, with extensive optimization techniques available.

AO* Algorithm

  • ✓ Handles decomposable problems that cannot be solved by standard path search.
  • ✓ Natural representation for hierarchical planning problems.
  • ✓ Extracts an optimal solution graph (not just a path).
  • ✓ Efficiently models both mandatory sub-goals (AND) and alternatives (OR).
  • ✓ Foundation for modern game tree algorithms and theorem provers.

Future Scope

  • Weighted A*: Implement weighted heuristics (w·h(n)) to trade optimality for speed in time-critical applications.
  • D* Lite Algorithm: Extend A* to dynamic environments where obstacles can change during navigation (used in autonomous vehicles).
  • Monte Carlo Tree Search (MCTS): Integrate MCTS for probabilistic game tree search, used in modern game-playing AI like AlphaGo.
  • Bidirectional A*: Implement search from both start and goal simultaneously to significantly reduce search space.
  • Multi-Agent Planning: Extend AO* to coordinate multiple AI agents solving sub-problems simultaneously.
  • Deep Learning Heuristics: Use neural networks to learn optimal heuristic functions from training data, creating Learned Heuristic A*.
  • 3D Pathfinding: Extend the A* grid to 3D space for drone navigation and volumetric game environments.
  • Natural Language Interface: Allow users to describe problems in natural language, which are then converted to AND-OR graphs for AO* solving.

Through this project, we have demonstrated that AI search algorithms are not abstract concepts but practical tools with real-world applications in navigation, gaming, robotics, and decision support systems. The connection between A* (path search), AO* (decomposable problem solving), and Minimax (adversarial game play) shows the unified nature of informed search in artificial intelligence.

The system serves as both an educational tool and a foundation for more advanced AI research, providing clear visualizations and explanations that make these algorithms accessible to students, researchers, and practitioners alike.
