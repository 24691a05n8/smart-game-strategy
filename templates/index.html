TECHNICAL OVERVIEW

How the Algorithms Work

A*

A* Search Algorithm

Best-First Search with Admissible Heuristic

f(n) = g(n) + h(n)
g(n) — Actual cost from start h(n) — Heuristic estimate to goal f(n) — Total path cost estimate
  • ✓ Complete: Always finds a solution if one exists
  • ✓ Optimal: Finds the least-cost path
  • ✓ Uses Manhattan/Euclidean distance heuristic
  • ✓ Priority queue (min-heap) for efficiency
AO*

AO* Search Algorithm

Heuristic Search on AND-OR Graphs

Cost propagation in AND-OR tree
OR node — min cost among children AND node — sum of all children costs h(n) — Heuristic at each subgoal
  • ✓ Solves decomposable problems
  • ✓ Handles AND-OR graph structures
  • ✓ Optimal solution graph extraction
  • ✓ Bottom-up cost propagation
